# Map label glyphs

Signed-distance-field glyph ranges for MapLibre's label layers, served from
`/glyphs/{fontstack}/{range}.pbf`. The layer's `text-font` is `["noto-sans"]`,
which is why the folder has that name.

Font: Noto Sans (SIL Open Font License 1.1), glyph PBFs generated by the
MapLibre project (demotiles.maplibre.org). Ranges cover Latin, Latin
Extended A/B/Additional, combining diacritics and general punctuation — enough
for every polity name in the historical-basemaps data.
