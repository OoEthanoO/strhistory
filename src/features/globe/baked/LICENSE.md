# Historical border data

`prebaked_1783.json` is a simplified derivative of
[aourednik/historical-basemaps](https://github.com/aourednik/historical-basemaps),
licensed under [GPL-3.0](../../../../../public/data/snapshots/LICENSE.md).

Regenerate it from the local historical border file with
`node scripts/data/build-prebaked.mjs`. Coastline detail is deliberately reduced
for the immediately rendered, interactive SVG globe.
